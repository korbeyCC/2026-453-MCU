# 2026-273 PID 阶跃响应分析与调试上位机

本上位机是专为 2026-273 升降控制系统（或任意单片机闭环系统）定制的高颜值、无阻塞实时波形分析工具。它遵循公司 PC 辅助工具开发规范，采用现代化扁平风格设计，集成了**物理串口多线程接收**、**内置闭环系统仿真器**以及**自动阶跃响应时域指标计算**。

---

## 核心功能介绍

1. **多线程安全串口通信**
   - 采用独立后台线程接收串口字节，杜绝大波特率下数据流卡死、白屏或未响应问题。
   - 实时日志显示，不同级别（系统/数据/警告/报错）字体高亮着色。

2. **内置一阶时滞惯性系统模拟器**
   - 端口下拉框选择 `Simulation (模拟器)` 连接。
   - 支持实时修改左侧的 **Kp**、**Ki**、**Kd** 仿真参数（即时生效）。
   - 点击“模拟施加 10.0 阶跃信号”按钮，可观察典型的 PID 调节波形和指标计算。无硬件时亦可供算法联调与操作演示。

3. **全自动时域指标计算 (Step Response Analytics)**
   - **自动阶跃识别**：实时监测目标值变化。当检测到目标值发生突变时，自动判定为一次“阶跃事件”，并开启分析计数。
   - **核心指标计算**：
     * **目标值**：当前所追求的稳态设定值。
     * **超调量 (Overshoot)**：以百分比呈现系统调节过程中的最大过冲。
     * **上升时间 (Rise Time)**：系统实际值从 10% 变化量到达 90% 变化量所消耗的时间（用**蓝色虚线**在图中标注）。
     * **调节时间 (Settle Time)**：系统实际值进入目标值 $\pm 2\%$ 误差带且此后不再超出该范围的耗时（用**红色虚线**在图中标注）。
     * **稳态误差 (Ess)**：系统进入稳态后的最终误差。
   - **图形化标注**：在实时 Canvas 画布上，系统会自动圈出最大值点、阶跃起点、上升时间线和调节时间线，方便直观分析。

## 串口通信协议规范

单片机在通过串口或 RTT 上报数据时，只需使用简单的文本输出，上位机即可自动解析。兼容以下两种格式（推荐每 **10ms - 50ms** 上报一次）：

### 格式 1：纯数字 CSV 格式 (极简推荐)
格式为 `目标值,当前值\r\n`。
**下位机示例：**
```c
printf("%f,%f\r\n", target_val, actual_val);
// 例如输出: 10.00,8.45
```

### 格式 2：键值对格式 (防干扰能力强)
格式中包含 `t` 或 `target` 以及 `a` 或 `actual` 关键字。
**下位机示例：**
```c
printf("target:%f, actual:%f\r\n", target_val, actual_val);
// 或简写为:
printf("t:%f, a:%f\r\n", target_val, actual_val);
```

## 快速开始

### 方式 1：使用 Python 源码运行
1. 确保已安装 Python 环境，进入本上位机根目录。
2. 安装依赖库：
   ```bash
   pip install pyserial
   ```
3. 启动上位机：
   ```bash
   python src/data_analyzer.py
   ```

### 方式 2：使用 PyInstaller 自动编译打包运行
1. 双击运行根目录下的 `build.bat`。
2. 脚本将自动执行 PyInstaller，在后台编译并生成单文件免安装绿色版程序。
3. 编译完成后，直接运行 `dist/data_analyzer.exe` 即可。
